- 修改输入时先读 [连携与验证](references/combat.md)。分别定位动作拥有者、预输入开始帧、允许实际打断的帧以及关闭条件。逐帧通过正常控制器入口回放。

- 安装前确认 title ID 0100770008DD8000 和实际运行的便携 Yuzu 目录。先在独立桌面、独立 user 目录、音量 0 的实例检查本次启动的插件与钩子日志。只结束隔离进程。正式会话运行中就安排退出后安装。保留玩家启用的 60FPS 配置。
- 存档下载和上传分别使用明确标有方向的入口。按玩家指定的云端或本地作为来源；单独更新 MOD 时只交付 MOD。发布安装包要核对源码补丁可重放、安装文件和发布资产的 SHA-256。
