# 太刀连携与回归

## 输入和动作所有权

Xbox RT 是武器气刃键，RB 是冲刺。Y、B、A 分别对应 Switch X、A、B。摇杆和冲刺不能合成 RT。测试首次收刀移动拔刀、起身的原生排队请求、摇杆回中与方向输入；红刃站立拔刀出原地赤刃，移动拔刀出对应方向的移动赤刃。保留正常开刃和 GU 原生单键连携。

普通刀和赤刃允许挥空垫刀，连携窗口内 RT＋B 接见切。自由态与刚出见切时不能直接见切。完整覆盖双键同帧、两种顺序、间隔 1–4 采样且短暂重叠、提前松开、单键、无重叠、第三键污染、换动作、被打断及命中停顿。逐项记录第一次允许输入和第一次实际出招。狩技只接受后摇中的新组合，不把中途按住的键带进收势。樱花末段 F1，圆月收势 phase 2 F113，镜花成功反击 phase 1 F102。站架和未反击另测。

大回旋（原生、红见切派生、满蓄）、赤刃旋转斩、武士道气刃无双斩收势只派生红刃见切。预输入后逐帧切换无／白／黄／红，执行时读取结算后的颜色；单列黄刃命中升红与黄刃挥空。四档皆可 RT＋A 特殊纳刀。连按 A 不应偷跑翻滚，另外测解锁帧之后的新 A。武士道无双行动 67；其他风格即使共用动画也要分开测。勇气蓝保留原生档位与原有派生映射。

武士道大居合迎击成功 → 第一次 Y → 原生拖刀 → 拖刀减速时自动接一文字。拖刀中松开再按 Y 可在 GU 合法窗口提前出一文字 → 气刃足够时 RT 接无双。第一次 Y 的预存与生效分开；连按、方向、命中停顿不能重置计时或提前跨过拖刀。

## 气刃与登龙

普通升刃、耗刃、红刃计时和勇气蓝分开测。红刃气刃突刺命中 → 起跳 → 空中 → 下劈 → 落地扣一刃。起手红但挥空时计时继续，只有确认怪物碰撞且仍是原生红档才保护时钟。保留命中瞬间的剩余红刃时间，保留正常付费；落地衔接解放的额外消耗另算。用一帧剩余时间、零模拟步长、持续相同动作、运动绑定替换、受伤、猫车、切区、换角色、蓝刃分别测试。硬上限按原生计时消耗，不能每帧重置。记录起手红的登龙速度是否贯穿各段。

## 验证层次

控制器回放检验时机，计时器桩检验边界，隔离启动检验插件加载。只有任务内实际命中才能确认碰撞回调次序和手感。比较旧、新独立测试函数的结果，并列出既有失败。核对动作攻击范围时同时检查挂点到刀尖的覆盖和命中帧。完整动作表见同标签 docs/combos.md。
